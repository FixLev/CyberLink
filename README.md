## 📖 О проекте

**CyberLink** — это современный децентрализованный мессенджер, работающий по технологии **P2P (Peer-to-Peer)**. В отличие от традиционных мессенджеров (Telegram, WhatsApp, Viber), CyberLink не использует центральные серверы — все данные хранятся только на устройствах пользователей.

### 🌟 Ключевые особенности

- 🔗 **Полная децентрализация** — Никаких серверов, только прямые P2P соединения
- 🔒 **Безопасность** — Все сообщения шифруются и передаются напрямую
- 💾 **Локальное хранение** — Ваши данные принадлежат только вам
- 📱 **Кроссплатформенность** — Работает на Windows, Linux, macOS, Android и iOS
- 🔄 **Автообновление** — Автоматическое обновление через GitHub
- 🌙 **Киберпанк дизайн** — Уникальный стиль с неоновыми цветами
- 📨 **Мгновенные сообщения** — Быстрая доставка через P2P
- 👥 **Групповые чаты** — Поддержка групповых обсуждений (в разработке)
- 📎 **Обмен файлами** — Отправка файлов через P2P (в разработке)
